# 雀樂協會官網 QA / 品管檢核

## 1. 內容與醫療資訊
- 每一篇健康／減害頁面有「最後更新日期」。
- 醫療、藥物、感染、法規內容引用 WHO、台灣主管機關或明確專業指引。
- 區分「協會既有資料」與「外部研究／官方資料」，不把推論寫成協會歷史。
- 使用不污名、以人為本的語言，不以恐嚇圖片或羞辱作為健康教育手段。
- 任何高風險或急性症狀頁面均提醒尋求緊急醫療，而非提供個別診斷。

## 2. 隱私與資安
- 第一版不啟用會員、登入、密碼或健康資料蒐集。
- 不公開會員繳費狀態、私人 email、電話或非必要個資。
- 未來若加入報名：HTTPS、最小化蒐集、權限分層、密碼雜湊、稽核紀錄與資料保存政策為上線前必要條件。

## 3. 著作權
- 不把第三方新聞頁截圖當作網站常駐圖片庫。
- 活動外部來源以文字摘要＋原始連結為主。
- 使用照片前確認協會自有、明確授權、開放授權或來源網站明確允許之條件。

## 4. UX / 無障礙
- Logo 永久出現在 header，點擊回首頁；footer 再出現一次。
- 鍵盤可操作所有導覽與連結，提供 skip link。
- 文字對比、焦點狀態、圖片 alt、語意標題階層符合 WCAG 2.2 AA 目標。
- 手機 360px、平板 768px、桌機 1440px 檢查不溢位。

## 5. 效能與 SEO
- 靜態輸出，圖片使用 WebP/AVIF（Logo 原檔除外可再優化）。
- Lighthouse Performance / Accessibility / Best Practices / SEO 目標皆 >= 90。
- 每頁有唯一 title、description；正式網域確定後更新 metadataBase、canonical、sitemap、robots。

## 6. 佈署可攜性
- 原始碼完整存於協會 GitHub repository。
- 不把不可攜的核心資料存進單一部署商專有服務。
- 可用 `npm run build` 產生靜態 `out/`，能部署到 Vercel、Cloudflare Pages、Netlify 或一般靜態主機。

## 7. 上線前人工驗收
- 協會秘書確認：正式聯絡資料、現任理監事、英文名稱、公開地址、所有活動文字。
- 專業審稿者確認：高風險健康內容與台灣在地資源。
- 抽查 100% 外部連結，避免失效或錯誤導向。
